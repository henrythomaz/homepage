# Henry Campos — Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content notes

- The portfolio sections are composed in `src/App.tsx`.
- Navigation items are defined in `src/constants/index.tsx`.
- Public GitHub repositories are loaded from the `henrythomaz` GitHub account.
- The downloadable CV is `public/cv/henry-campos-cv.pdf`. Replace that file to publish an updated version; the download buttons already point to it.
- The project uses `/homepage/` as its Vite base path for GitHub Pages deployment.

The testimonials area intentionally presents collaboration principles instead of fabricated client reviews.
